# 0x4d4d4f.github.io

A terminal that boots, at [0x4d4d4f.github.io](https://0x4d4d4f.github.io).

- `site/index.html` is the page: one file, no dependencies.
- `scripts/render.mjs` draws the neofetch on the GitHub profile and the
  numbers the page shows, from GitHub's API.
- `.github/workflows/pages.yml` builds both daily and publishes them with
  GitHub Pages, so nothing generated is ever committed.
